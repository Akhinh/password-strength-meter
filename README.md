# Password Strength Meter

## Overview

This project is a simple web application that evaluates the strength of a password and provides feedback as Weak, Medium, or Strong(with additional colors telling each one respectively).

---

## Features

* Password input field
* Strength evaluation
* Color-coded feedback
* Simple and clean UI

---

## Technologies Used

* HTML
* CSS
* JavaScript

---

## Project Structure

password-strength-meter/
│── index.html
│── style.css
│── script.js
│── README.md

---

## Strength Logic

* 0–2 → Weak
* 3–4 → Medium
* 5 → Strong
